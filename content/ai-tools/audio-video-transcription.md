<section class="page-hero"><p class="eyebrow">AI WORKFLOW GUIDE</p><h1>Audio and video transcription: a practical workflow</h1><p class="lede">Prepare permitted recordings, correct transcripts and export usable notes without treating AI output as a verified record.</p></section><article class="prose"><h2>Start with permission and an intact source</h2>
<p>For your own tutorial, interview or meeting recording, preserve the original and work on a copy. For another person's video, check the owner's terms and permission before downloading, transcribing or republishing it. A publicly watchable video is not permission to publish its transcript. If permission is unclear, ask the owner before using the recording.</p>
<h2>Define what you actually need</h2>
<p>A transcript preserves words, a subtitle file adds timed segments, and a summary selects conclusions. Decide which output the task requires. If you need subtitles, verify that the chosen export includes timestamps and opens correctly in your player or editor. If you need research notes, preserve source timestamps so that a claim can be checked without replaying the entire recording.</p>
<h2>Prepare a useful sample</h2>
<p>Listen to the source first. Note where sound drops out, where speakers overlap and where technical terms occur. Do not assume an enhancement filter recovers words that were never captured. Test a copy before processing the complete recording. Avoid repeatedly converting files merely to satisfy an upload limit; check accepted formats, file size and recording duration first.</p>
<h2>Listen again to names, numbers and negations</h2>
<p>Correct names, amounts, dates, negations and instructions against the audio. A missing word such as “not” can reverse the meaning of a sentence. Keep uncertain passages marked as uncertain instead of completing them from context. For an interview, verify speaker labels before attributing a quotation. For a technical tutorial, check command names and file paths separately; a fluent transcript can still contain an unusable command.</p>
<h2>Keep transcription and translation separate</h2>
<p>When the output language differs from the recording, retain the source transcript as well as the translation. Resolve uncertain source words before translating them. Do not use a polished translation as evidence that the original transcription was correct. If a language or mixed-language feature is important, check the provider's current support documentation and test your own permitted sample.</p>
<h2>Export before you commit</h2>
<p>Open the downloaded file in its destination application. Check encoding, punctuation, timestamps and paragraph breaks. For a subtitle file, play it alongside the video and check whether the timings remain synchronized. Keep an unedited export and a corrected copy so later changes can be compared. Share only the version you intend recipients to use.</p>
